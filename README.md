#### Machine Learning for MDR prediction from clinical isolates-Northern Ghana
prediction of multidrug _Resistance bacteria using Random Forest,SVM, and GLM models

####Datasets 
Clinical Isolates from Northern Ghana hospitals

###Methodology
Data cleaning with 17 antibiotics
10-fold cross-validation, 5 repeats
Models:RF, SVM-radial, GLM

###Packages
R-caret, randomForest,e1071,ggplot2
